# Prototipo navegable

Prototipo de baja fidelidad hecho en Figma, con 17 pantallas conectadas para el cliente y el administrador.

**Abrir el prototipo:** https://www.figma.com/proto/DIk61UxS75bwQ4BGkjkLap/Prototipo---Reservas-de-canchas?node-id=1-5&starting-point-node-id=1%3A5&scaling=scale-down

## Pantallas

| # | Pantalla | Caso de uso |
| --- | --- | --- |
| 01-02 | Disponibilidad (hoy y sábado) | CU1 |
| 03 | Aviso de horario ocupado (flujo alterno 2a) | CU3 |
| 04-06 | Formulario de reserva (vacío, error en el celular, listo) | CU2 |
| 07 | Reserva creada | CU2 |
| 08-09 | Adjuntar comprobante | CU4 |
| 10 | Mis reservas | CU4, CU7 |
| 11-12 | Confirmar cancelación y reserva cancelada | CU7, CU8 |
| 13 | Inicio de sesión del administrador | CU9 |
| 14 | Panel de reservas del día | CU9 |
| 15 | Detalle de la reserva | CU9, CU5 |
| 16 | Anticipo confirmado | CU5 |

Las capturas están en la carpeta `pantallas/`.
